 Chocolate Sales Analysis

This project focuses on analyzing chocolate sales data to understand **sales performance, product performance, customer behavior, and store performance**.

Tools Used

* Excel
* SQL
* Power BI
* Python
* Pandas
* Matplotlib

Analysis Areas

* **Sales Analysis** – Revenue, profit, quantity sold, and sales trends
* **Product Analysis** – Product, brand, category, and cocoa percentage performance
* **Customer Analysis** – Customer count, age groups, gender, and loyalty membership
* **Store Analysis** – Store performance and sales distribution

 Project Goal

The main goal of this project is to transform raw chocolate sales data into meaningful insights using **data cleaning, SQL queries, Excel analysis, Python, and interactive Power BI dashboards**.

Datasets

* `customers.csv`
* `products.csv`
* `sales.csv`
* `store.csv`
* `calendar.csv`
